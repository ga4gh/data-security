# GA4GH Data Security Work Stream

The GA4GH Data Security Work Stream is a foundational work stream that focuses on security, privacy, and compliance across all GA4GH products.

## Authentication and Authorization Infrastructure (AAI)

The AAI specification is now in the [ga4gh/aai](https://github.com/ga4gh/aai) repository.

GA4GH AAI and Passports provide secure, standards-based data access in cases where the data access committee / data steward is not tightly coupled with the data holder.

Standards and implementation practices for protecting the privacy and security
